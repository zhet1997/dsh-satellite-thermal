# 卫星热设计工作台使用指南

适用版本：0.2.0 ｜ 面向已安装插件的 DSH 网页用户

热设计工作台用于整理资料、编辑热模型、设置工况，并通过远程 NX/Simcenter 计算。网页与对话助手共用同一个项目。

**基本流程：创建项目 → 导入几何与资料 → 核查热模型和参数 → 设置工况 → 新增计算 → 查看结果。** 保存参数只更新输入版本，不会自动启动计算。

## 1. 打开工作台与选择项目

登录 DSH 网页，在一个会话中点击输入区的 **“热建模工作台”**。工作台在右侧打开，左侧保留对话；可拖动分隔条调整宽度。

点击顶部 **“＋”** 创建项目，或从下拉框选择已有项目。项目会与当前会话绑定；切换会话后，需要为该会话新建或选择项目。多个会话可以明确选择同一个项目协作。

顶部的 `v1`、`v2` 等表示**项目输入版本**。修改参数并保存后版本更新；已提交的计算使用当时的固定输入，不会被后续编辑覆盖。

### 必要时配置微服务连接

如果提示服务未连接，进入 DSH **设置 → 内置插件 → 卫星热建模**，填写管理员提供的**热服务地址**和访问令牌，检查连接后保存。

热服务地址必须能从 **DSH 服务器**访问；不要填写自己电脑的本机地址，也不要误填 NX 执行器地址。NX 执行器由热服务连接。

热服务在线但 NX 未连接时，仍可编辑，计算任务会等待连接，请联系管理员检查执行端。

## 2. 导入几何与资料

### 几何

在 **“资料与几何”** 中点击几何入口，或拖入 `.step`、`.stp` 文件，也可使用几何插件提供的交付 ZIP。解析完成后，检查组件数量、形状及名称。

默认按 STEP 个体选择组件。壳/薄板分析需提供实际曲面或中面及厚度，仅修改模型类型不能代替中面建模。

更换几何会重新建立组件与连接，建议先导出项目。

### 资料

根据资料用途选择入口：

| 入口 | 建议上传的内容 |
|---|---|
| **重点资料** | 已筛选的设备参数表、材料属性、功耗预算、工作温限等关键资料 |
| **辅助资料** | 较长的验收报告、招标文件、总体报告等，系统先筛选热设计相关片段 |

支持 Excel、CSV、Word、文字型 PDF、JSON 和文本；也可粘贴文字。扫描件需先转换为可搜索文本。

资料在后台分析，可继续其他操作。展开下方资料记录可查看状态、摘录和来源。“已提取”不表示整份资料全部理解，仍需核查采用值。

**参数表尽量使用与几何一致的组件名称，并明确标注单位。** 例如：

| 组件名称 | 材料 | 功耗(W) | 发射率 | 吸收率 | 温限下限(℃) | 温限上限(℃) |
|---|---|---:|---:|---:|---:|---:|
| 星务计算机 | 铝合金6061 | 8 | 0.8 | 0.2 | −10 | 50 |

上表仅演示格式。名称无法匹配或内容未识别时，可通过对话或参数表补充。

缺失或明显异常的普通热参数可用估值补全，并保留标记；已有用户输入不会被后台资料分析直接覆盖，冲突需人工核查。**工作温限不自动估算，没有依据时留空。**

覆盖图反映资料/确认程度，不代表模型准确率；估值不计为已确认，连接覆盖不保证路径齐全。辅助资料采用关键词筛选，重要要求建议另外整理为重点资料。

## 3. 编辑热模型与设置工况

### 查看组件和连接

进入 **“热模型”**，可切换“联动视图”“热拓扑”“三维模型”。面板较窄时，单独查看三维或拓扑，并按需收起对象属性。

三维中拖动旋转、滚轮缩放、点击组件；点击拓扑节点或连线，在对象属性区修改并保存。拖动节点只调整图布局，不改变几何或触发计算。三维与拓扑的组件颜色对应，不代表温度；辐射连线默认弱化，可切换关系筛选查看。

点击 **“添加热连接”** 或拖动组件端口建立连接，选择两端对象和采用值；必要时指定表面。

| 热连接类型 | 填写内容 | 单位 |
|---|---|---|
| 接触热阻 | 面积接触热阻，不要与总热阻混用 | m²·K/W |
| 导热连接 | 该传热路径的总热导 | W/K |
| 表面辐射 | 配置交换系数，不是已计算的视因数 | 无量纲 |

点击 **“添加边界”** 可设置空间辐射、外部热流或规定温度，并选择施加对象。**温度边界使用 K，热流使用 W/m²**，以表单标注为准。不要将同一热源或载荷重复施加。

### 轨道与工况

轨道设置位于热模型内。点击 **“轨道 / 工况”** 或拓扑中的 **“轨道与环境”** 节点：

1. 填写轨道参数及季节。半长轴单位为 km，不能直接用轨道高度代替。
2. 点击 **“计算六向外热流”**，查看曲线与推荐的冷态、热态工况。
3. 如需指定时刻，输入秒数或使用时间选择器，再点击 **“生成工况”**。
4. 也可通过 **“手工工况”** 输入六向载荷，或导入已有外热流资料。

方向约定：`+Z` 朝地心、`−Z` 朝天顶、`+X` 沿轨道方向、`+Y` 沿轨道法向，应核对模型坐标。

冷/热工况按六向入射热流等权和的最低/最高值推荐，六向值取自同一时刻。**它们是环境载荷工况，不保证是设备温度的最低/最高时刻。** 手工热流填写未乘吸收率的入射值。

计算外热流只更新工况，不启动 NX 温度求解。若仍显示“外热流待补充”的默认零热流工况，应先完善环境设置。

## 4. 核查参数并保存

在 **“参数核查”** 中搜索组件，或筛选含估算值的条目：

- 功耗、发射率、吸收率、工作温度上下限可直接在单元格修改，按 Enter 或离开输入框保存。
- 材料、导热率、模型类型等可点击组件名称或编辑按钮修改。
- 多个组件使用相同值时，勾选后点击 **“批量编辑”**。
- **“查看标准输入”** 可检查并下载下游实际采用的参数；网格与背景设置在下方折叠区。

参数旁的标记区分 **资料、估算、用户输入、推导**，悬停可查看来源。材料参考常数不等于经认证的牌号数据，应重点核查关键导热路径上的估值。

工作温限在网页显示为 **℃**；温度边界和内部标准输入采用 **K**。没有温限时留空，只设置一侧就只检查一侧。

提交计算前，至少核查以下内容：

1. 组件身份正确，功耗总量及单位合理。
2. 主要材料、连接和边界有依据，估值影响已了解。
3. 轨道方向与工况正确，没有误用默认零热流。
4. 需要判定是否合格的设备已填写工作温限。

保存后核对采用值。遇到版本冲突时，先核对最新输入，再重新保存。

## 5. 提交计算与检查结果

### 新增计算

进入 **“运行与结果”**，确认“当前输入 vN”，选择一个工况或“全部已设工况”，点击 **“基于当前修改新增计算”**。

每个工况对应一条运行记录，使用固定输入快照。旧任务继续，新任务排队；相同输入已有活动任务时，重复点击会复用任务。

提交后流程默认自动推进，不在每个阶段停下来要求确认。可随时查看进度，必要时取消所选运行；正在执行的任务需要等待执行端确认停止。

运行依次经历排队、建模、核查、求解和结果提取。若显示“等待 NX 连接”，检查执行端；若“运行异常”，查看阶段消息与文件，修正后重新提交。

### 核查实际模型

选择运行，打开 **“实际模型核查”**，检查 NX 回传的网格、材料、连接和条件。**STEP 预览不等于 NX 有限元模型**，实际施加情况以运行回读为准。

### 查看温度与温限

打开 **“温度与检查”**，查看真实温度云图、组件最低/平均/最高温度及工作上下限。

- **蓝色：** 低于工作下限，显示低温超限幅度。
- **红色：** 高于工作上限，显示高温超限幅度。
- **未设置温限：** 缺少合格判据，不能判断为通过。
- **温度未完整回读：** 结果不足，需要检查执行过程。

结果使用**本次运行快照中的温限**。如果修改了当前参数或温限，需新增计算后查看对应结果。缺少真实温度数据时，组件区分色不会被当成温度云图。

能量平衡需结合项目容差判断。点击 **“本次输入快照”** 可追溯采用参数。

### 导出

顶部 **“导出项目”** 下载项目、标准输入、运行快照和已登记工件；运行页底部可单独下载已生成的工程与结果文件。建议更换几何和阶段性交付前导出留档。

## 6. 用对话助手协作

点击工作台 **“对话”**，输入问题后带入左侧草稿，检查并发送。项目、版本和选区会一并提供给助手，长资料默认只提供摘要和按需检索的片段。

> 检查当前项目缺少哪些材料、功耗和工作温限，列出估值及依据，不启动计算。

> 在辅助资料中查找工作温度和热耗要求，返回文件名、页码或行号及原文；没有命中时说明检索范围。

> 将选中设备的发热功率改为 18 W，依据为设备规格书第 12 页，保存但不计算。

明确区分“核查”“修改并保存”和“提交计算”，修改后在工作台核对采用值与来源。

## 7. 常见问题

| 现象 | 建议处理 |
|---|---|
| 工作台提示服务未连接 | 核对插件设置中的热服务地址和令牌；服务器不可达时联系管理员 |
| 热服务在线，NX 未连接 | 可继续编辑；请管理员检查执行器，连接恢复后排队任务可能继续 |
| 上传后参数没变化 | 查看分析状态、组件名称匹配和单位；已有人工值可能受保护，展开资料查看冲突 |
| 保存后没有运行记录 | 正常；到运行页点击“基于当前修改新增计算” |
| 结果与当前参数不一致 | 检查运行对应的输入版本，历史结果使用旧快照 |
| 侧栏拥挤 | 拖宽面板，切换单独的三维/拓扑视图，按需收起对象属性 |

当前版本以稳态为主，暂不提供瞬态、扫描资料 OCR 和正式排版报告。复杂壳、辐射组合及面热流需核查执行器支持范围。
